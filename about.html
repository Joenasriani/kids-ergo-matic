ERGO-MATIC

Play the game · Source repository

Game rule

The player rolls a 3D die to move a robot along an ergonomics-question path. Landing on a question tile opens a three-choice prompt.

roll die → move → answer → update score/lives → continue toward finish

Correct answers add 20 points. Incorrect answers remove 5 points, remove one of two lives, and return the robot to its position before the roll.

Topics

The built-in bank includes monitor position, wrist position while typing, backpack use, phone viewing height, mouse grip, foot support, lifting, sitting posture, movement, breaks, eye care, monitor distance and elbow angle.

Activation context

This game belongs to the same kids-* game set developed for the multi-game interactive children’s edutainment activation in the UAE.

Evidence boundary

The questions are simplified game content rather than a complete ergonomics standard. The repository contains no study measuring posture change, injury prevention, retention or transfer outside the game.
