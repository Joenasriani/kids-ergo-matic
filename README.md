# ERGO-MATIC

**Status:** original educational browser board and quiz game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

ERGO-MATIC is a child focused ergonomics game. Players roll a 3D die, move a robot along a board, answer ergonomics questions and collect points.

Historical label: **Ergo-Matic**.

The historical label and ERGO-MATIC title belong to the same game lineage.

Topics in the game include screen height, typing posture, backpack use, phone posture, lifting, movement breaks, eye care and desk setup.

Existing branches and historical files are retained as development history.
